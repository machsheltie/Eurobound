# Eurobound: the story so far

Compiled 2026-11-14 for bead Eurobound-c8xn. Author request, verbatim: "we need an agent to start reviewing our admittedly spotty game story and put together what we have so far so I can fill it in."

**What this file is.** A compilation of story facts that are already written down in the repo, with where each one is recorded. Nothing here is new. Where the story has a gap, this file asks a question and leaves the answer blank.

**How to read the tags.**

- **[AUTHOR RULING]**: the author said it, and the rulings ledger, the Eurobound Desk or a bead records it.
- **[CANON DOC]**: it is in a design doc that the ledger counts as author-approved, but there is no separate ruling on that exact statement.
- **[DRAFT/UNCONFIRMED]**: it appears in a doc, but nobody ruled on it, or the plot it belonged to was struck.

**Short names for sources.** "LEDGER" is `docs/superpowers/NEXT_WORK.md`. Line numbers are as of 2026-11-14. Paths without a folder prefix are under `design/`.

**The short version.** The premise, the three bros, the tone rules, the city order, step 1 of the opening and a large body of optional side content are settled. The main story itself is not written: `design/narrative/mainquest.md` is a four-line placeholder. There is no recorded main-quest beat for any of the four cities, and the finale is four named parts with no content. Section 4 lists 46 questions.
