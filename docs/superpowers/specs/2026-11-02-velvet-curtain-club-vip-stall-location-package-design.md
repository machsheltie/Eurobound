# Velvet Curtain Club VIP Stall Location Package Design

## Intent and Identity

Define the VIP Stall as a separate bathroom micro-location inside Velvet Curtain Club for NFT discovery, Fistø lore, and status-dependent perception.

- Location ID: `debaucheryville_velvetcurtain_vipstall_bathroom_01`
- Slug: `velvet_curtain_club_vip_stall`
- NPC folder: `Velvet_Curtain_Club_VIP_Stall`
- Primary source: `velvetcurtainclubvipstall.md`

## Visual and Spatial Design

Velvet Curtain Club owns the trail, bouncer pair, `STAFF ONLY` curtain, plaque, and gate. This package begins behind the curtain in a compact single stall with stained black-velvet toilet seat, champagne holder and old bottle, selfie-filter mirror, cracked tile and hidden QR code, RGB shimmer, bass bleed, graffiti/lore surfaces, and return threshold.

Nodes are threshold, fixture, mirror/selfie camera, champagne prop, cracked-tile QR point, Fistø lore surface, and exit. Drunk and hungover states modify overlays and reveal cues without changing physical topology.

## Gameplay, Quests, and State

The club must be open and entered. The parent sets `velvet_vip_stall_entrance_discovered`; passing the exterior Bravado gate sets `velvet_vip_stall_access_unlocked`. Inside, reading the hidden `DO NOT LOOK AT THE BABY` graffiti sets `meme_black_market_graffiti_clue_read`, which the Internet History Museum consumes. The package also owns NFT #2 `item_pixelated_kebab_monkey`, which sets `pixelated_kebab_monkey_obtained`, plus status-enhanced visuals, hungover Fistø lore, NFT Affinity Protection, CryptoMamiXXX ICQ bindings, selfie interactions, and return. `nfthuntdebaucheryville.md` and couchsurf quest files own dialogue and global progression.

## Package Directives

Items distinguish NFT discovery records, buffs, bottle/prop examinations, and quest-owned messages. Environment provides bass-sync and RGB-safe variants. NPCs should not duplicate the exterior bouncers; include only a documented attendant or ambient presence inside. PNG and mapping cover stall faces, velvet fixture, mirror UI/filter states, tile/QR reveals, graffiti, props, status overlays, buff UI, and reduced-flash states.

## Validation

- Parent gate and child interior ownership do not overlap.
- NFT #2 uses the global hunt's exact identifier, and the museum clue exports its exact shared flag.
- Drunk/hungover overlays never hide the base QR interaction.
- Bouncers are referenced, not respawned inside.
- The only physical exit returns to Velvet Curtain Club.
