# Debaucheryville Location Packages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce complete, schema-compatible eight-file packages for all 25 remaining Debaucheryville locations.

**Architecture:** Each location is implemented and validated as an independent package using its child plan. A final portfolio pass validates unique IDs, shared transitions, brewery order/rewards, NFT mapping, parent-child ownership, and authoritative PNG mappings across all 200 deliverables.

**Tech Stack:** JSON, Markdown, PowerShell JSON validation, Godot 4.4 HD-2D content conventions

**Spec:** `docs/superpowers/specs/2026-11-02-debaucheryville-location-package-program-design.md`

## Global Constraints

- Produce exactly seven JSON files and one PNG requirements Markdown file per location.
- Implement the 25 child plans in dependency order.
- Preserve existing correct Astronomical Cock-Up Square, Euro Ink 4 Less, and Tram Stop #17 content while filling/reconciling gaps.
- Never duplicate a child interior in its parent package.
- Use exact shared flags, NFT IDs, brewery item IDs, and PNG target names from the program spec.
- Preserve unrelated working-tree changes.

## Review Focus

- All 175 JSON files parse.
- Exactly 25 authoritative PNG documents exist.
- Every package has one shared, unique location ID.
- Cross-location destinations and flags resolve bidirectionally.
- Archived/hash-prefixed PNG documents do not become co-authoritative.
