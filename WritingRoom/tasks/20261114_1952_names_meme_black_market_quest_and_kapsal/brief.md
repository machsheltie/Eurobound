# Brief: two naming jobs, three options each (the author names; the room only offers)

## Audience (author, 2026-11-14)
"I have told it several times the game is for younger Gen X/xennial/millenial women". The names land for her: funny, specific, laughing AT the bros or the tourist trap. Not highbrow.

## Rules for every name
- **Unique across the game.** Check `docs/catalog/` (quests.md, items.md, locations.md, status_effects_and_abilities.md, npcs.md) and grep `design/` for each candidate. A clash disqualifies it.
- **No real place names.** "Europe" is banned (author, 2026-11-15); the continent is Euromemeia. **No Dutch names** (author: "We use american names and they should be whitty, clever, satirical, parody type names that are fully americanized").
- Real brands, games and memes keep their real names where a name uses one.
- Short enough for a quest log line or a status badge.
- Funny, not clever-clever. A pun is fine if it reads at a glance.
