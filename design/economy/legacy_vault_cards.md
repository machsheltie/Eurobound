## 1. What This File Is

The Legacy Vault (Wallet Tab 1, unlocked from game start) renders one card per held asset. This
file is the **card copy** for all twelve Frat Bro NFT collection targets plus the FuncoLand
Nostalgia Series relic. Layout, framing, seals, the permanent Portfolio Thesis sub-header and the
`[N of ∞] The Legacy Vault Secured` counter live in `wallet_ui.md`; this file supplies only the
text that goes inside the frames.

**Card anatomy (per spec §2, fixed, four fields, in this order):**

| Field | Function |
|---|---|
| **Edition** | The scarcity claim. Always stated as fact, never hedged. |
| **Estimated Future Value** | Always absurdly bullish. Never a hedge, never a range that includes down. |
| **Collector's Note** | Gallery wall-text voice. Describes the artwork with complete seriousness. |
| **Acquisition Story** | Provenance, told with the gravity of an estate auction catalogue. |

### 1a. Writing rules for this file (binding)

1. **The Vault never winks.** No card, seal, tooltip, or footnote may signal that the assets are
   worthless. The Vault is a museum and it is written like one. The comedy is the distance between
   the framing and the object; nothing on screen closes that distance.
2. **No card contradicts the item's canon.** €0 is €0 everywhere in the game (see
   `_sorting/Design/Inventory/items/tractor_nft_item.md` development notes). The Vault card
   restates the bros' valuation, never the world's, and never changes the item's actual worth.
3. **Author-locked copy is reproduced verbatim** and is marked 🔒 below. It is not edited,
   improved, punctuated differently, or paraphrased.
4. **Real brands stay exactly as named** (§7a.1, closed). "America Online" and "FuncoLand" are
   brands and are exempt.
5. **No mascots.** No card gives an object a name-as-character, a personality, a voice, a
   relationship with the party, or an arc. Objects are assets. Assets do not talk.
6. Every card is legible to a player who has never seen the item. None of them explains the joke.
