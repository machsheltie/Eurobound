## 📱 Mobile Optimization Requirements

### Texture Compression by Platform:
- **iOS:** PVRTC 4BPP for orange glow effects
- **Android:** ETC2 with alpha for stealth indicators
- **Fallback:** PNG high quality for floor tile detail and patron sprites

### Sprite Atlasing Strategy:
- **Environment Complete Atlas:** Entrance + chandelier + booths + floor tiles + sconces + throne + furniture (1024x768)
- **Interactive Objects Atlas:** Patrons + goblets + props + signage + stealth elements (512x384)
- **NPC Atlas:** Bartender + nobles + bar flies + bouncer + Keg Sentinel (512x384)
- **Particle Effects Atlas:** Dust + foam + mustard + creaks + vomit + status effects (512x256)
- **UI Elements Atlas:** Status icons + brewery progress + stealth UI + boss UI + achievements (512x256)
- **Max Atlas Size:** 2048x2048 for mobile GPU compatibility

### LOD (Level of Detail) Scaling:
- **High-End Devices:** Full patron animations, all particles, complex lighting, chandelier flicker
- **Medium Devices:** Reduced patron detail, simplified particles, basic lighting
- **Low-End Devices:** Static patrons, minimal particles, stealth indicators only
- **Potato Mode:** Essential sprites only, no atmospheric effects, basic stealth puzzle

### Performance Targets:
- **Target FPS:** 40 fps (cramped space optimization)
- **Max Draw Calls:** 15 per frame
- **Memory Footprint:** 35MB maximum for location

### Visual Aesthetic:
- **Primary Theme:** "Medieval Slavic castle turned frat basement by failed architect"
- **Color Mood:** Rust orange dominance, faded royal purple accents, dive brown shadows
- **Lighting:** Flickering keg chandelier, hazy beer foam sconces, shadowed corners
- **Texture:** Moldy booths, gaffer tape repairs, mustard wall art, grease stains

### Character Design Philosophy:
- **Bartender Tracksuit:** Heritage pride treating health violations as tradition
- **Tanked Nobles:** Post-Soviet fashion meets medieval drinking culture
- **Slurring Bar Flies:** Drunk duo with synchronized vomiting comedy
- **Bouncer:** Aggressive enforcer taking dive bar seriously despite decay
- **Keg Sentinel:** Literal robot constructed from brewing equipment

### Puzzle Design:
- Stealth tile navigation requires spatial awareness with compromised space
- Safe tiles darker, creaky tiles lighter for visual distinction
- Patron obstacles create maze-like path through cramped room
- Audio warnings provide crucial feedback before failure
- Bouncer spawn creates meaningful consequence for mistakes

### Environmental Storytelling:
- Mini-keg chandelier suggests DIY frat basement conversion
- Gaffer tape repairs emphasize failed maintenance as "medieval"
- Moldy booths reveal health code violations accepted as normal
- Mustard wall art shows dive bar pretending to be cultured
- Velvet throne contrasts royal pretension with gritty reality
- Tracksuit nobles bridge post-Soviet culture with brewing heritage
