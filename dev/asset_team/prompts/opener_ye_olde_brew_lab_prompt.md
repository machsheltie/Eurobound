## Post-process

Magenta and the generator shadow keyed out, largest component kept. Classes assigned per full-res pixel by hue and luminance band (traces, LED, screen by cyan/green hue, plastic and metal by luminance bands, metal restricted to the opener plate and ring by position). Box-downsampled to 104 px tall on a 128 canvas by per-cell class vote, with thin classes (traces 16 percent, LED 20 percent) winning a cell on a lower threshold so 1 px lines survive. 3x3 majority on the body classes. The LED pattern is redrawn in code as 2x2-aligned abstract blocks in three staggered rows (the generated glyphs read as characters). The split ring is redrawn in code as a clean ellipse because the outline rule ate its thin stroke. Outline rebuilt on every 8-neighbour boundary plus 1 px under the base, 1 px upper-left highlight on the black plastic, code-drawn elliptical shadow. 64 is a 2x2 majority of the 128 (ties to the darker colour), 8-neighbour edges recoloured to the outline, the ring redrawn at native 64 size. One connected object, no semi-alpha.

## Choices where the doc is silent

Split ring added at the top so it reads as a keychain charm (the Keychain item clips it on); the doc does not say how it attaches. The engraved band sits at the cone base. "Algorithm Verified" is not rendered as text, only as abstract notches.
