# C9 joystick-with-lips graffiti (faint / glowing), round 3
Brief: PNG requirements doc, 12-field brief "C9 joystick-with-lips graffiti". Faint: dull smudged pink #B05080 at low opacity, lipstick smears only, no readable joystick. Glowing: ball and base #FF69B4, lips #FF00FF, outline #1C1C1C painted in, UV Purple #9400D3 halo. No nudity.
Source art: the round 2 Firefly glowing render ("Arcade Closet joystick-with-lips graffiti, GLOWING state ..."). Round 3 code clean-up (no new generation): one core silhouette mask is derived from that render. Glowing = the render inside the mask (black outline kept as painted pixels, not keyed out) plus a halo. Faint = only the lips region of the same render, smeared and noised in #B05080 at low opacity, same canvas and coordinates. Files `c9_joystick_glowing.png`, `c9_joystick_faint.png` (identical size, so they register).
