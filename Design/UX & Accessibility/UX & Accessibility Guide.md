IMPROVED VERSION (25% Enhancement)

Baseline:
- Screen reader strings, navigation behaviors, and focus order locked before alpha.
- Dynamic text scaling with font token system; enforce max line length rules.
- High-contrast palettes tested in Sim Daltonism, Coblis, and manual greyscale mode.
- Controller rumble event map with global toggle.
- Full keyboard/mouse + controller support with remappable keys and bindings.

Enhancements:
- Accessibility onboarding screen at first launch (text size, high-contrast, rumble, reduced motion).
- Automatic UI/resolution scaling across common desktop resolutions, windowed and fullscreen.
- Reduced Motion mode disables shakes, rapid animations, and particle clutter.
- Asset export pipeline step: automated colorblind simulation screenshot check before commit.
